include/   файлы AST, Visitor и интерпретатора
src/       точка входа программы
grammar/   грамматика Bison и лексер Flex
examples/  примеры программ
build/     сгенерированные и скомпилированные файлы

Поддерживается:

- объявление целых переменных
- присваивание
- операции `+`, `-`, `*`, `/` с обычными приоритетами
- круглые скобки в арифметических выражениях
- сравнение на равенство `==`
- `if/else`
- печать чисел, переменных и арифметических выражений

Запуск - в корне проекта make
После выполнения make исполняемый файл будет лежать в build и называться compiler

Команда make clean полностью удаляет `build/
